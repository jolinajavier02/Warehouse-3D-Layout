# User Workflow

## Data Governance

Use this page to manage data.

Main actions:

- Upload CSV, XLS, or XLSX files.
- Edit location rows.
- Add shop rows.
- Delete rows.

Any change in the table updates the map.

## Layout Strategy

This page shows the saved 3D map.

Click:

```text
+ Add Layout
```

to open the layout builder.

## Layout Builder

Builder tools:

| Tool | Purpose |
| --- | --- |
| `Zones` | Apply 3-zone layout and add ways inside a selected zone |
| `Shapes` | Add square, rectangle, long rectangle, circle, oblong, animal shape, custom block, boundary, or surface |
| `Signs` | Add entrance, exit, CR, fire exit, fire extinguisher, gate, way, partition, or gap |
| `Label` | Rename the selected block |
| `Color` | Assign color to selected item, blocks, lines, boundary, or surface |
| `Decorations` | Add tree, animal character, person walking, person standing, or chair setup |
| `Delete` | Select and delete a block |

Use the zone dropdown before adding items:

```text
Add layout in zone
```

This helps place new items inside a chosen zone and avoid overlap.

## Save And Undo

- `Undo`: returns to the previous builder state.
- `Save`: closes the builder and displays the updated map on Layout Strategy.

## Current Default Layout

The default layout includes:

- 3 warehouse zones.
- Green receiving zone.
- Peach left and right storage zones.
- White open zone.
- Gray ways/gaps.
- Purple dashed planning outline.
- Counted green and yellow rack blocks.
